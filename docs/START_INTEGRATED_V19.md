# Kakeibo v1.9.0 家計簿統合版：確認・利用手順

更新: 2026-10-25

## 現在地
- [開発ブランチ](https://github.com/EWSN-code/kakeibo/tree/feature/planning-v1.9) に、既存の家計簿と「資金計画」タブを統合した状態を保存済み。
- [PR #1](https://github.com/EWSN-code/kakeibo/pull/1) はDraftのまま。**main／公開版にはまだ配信していません**。
- Supabaseの追加テーブル・SQL変更は**現時点では不要**。既存 `updated_at` による条件付きクラウド保存を開発ブランチに実装。
- 既存取引、残高、積立、ほしいものは、計画の編集だけでは変更しません。

## 家計簿と一緒にローカルで開く（PC用）
1. GitHubの[開発ブランチ](https://github.com/EWSN-code/kakeibo/tree/feature/planning-v1.9) を開き、**Code → Download ZIP** を選択。
2. ZIPを展開。フォルダ内の `index.html` を直接ダブルクリックするのではなく、ローカルWebサーバーで開いてください（親画面と資金計画のiframeを同一オリジンで動かすため）。
3. Pythonが入っている場合、展開フォルダでターミナルを開き `python -m http.server 8765 --bind 127.0.0.1`（WindowsのPython Launcherなら `py -3 -m http.server 8765 --bind 127.0.0.1`）。
4. ブラウザで `http://127.0.0.1:8765/` を開く。普段の家計簿とは別のログインセッションになります。
5. ナビゲーションの「資金計画」を開いて編集。資金計画内の「読込」から相談用JSONテンプレートを読み込めます。

※ iPhone単体でこの手順を実行することは想定していません。スマホで一つのURLから使えるようにするには、別途公開環境への配信が必要です。

## 実データで使用する前の注意
1. いま使っている家計簿で **設定 → データ → JSON書出** を押し、完全バックアップを保存。
2. 旧版PWA・旧タブをすべて閉じてから、統合版を**1端末で**開く。旧バージョンは無条件upsert方式のため、同時使用を避ける。
3. 編集後、ヘッダーの「クラウドに同期済み」を確認する。同期停止表示が出たら作業を続けずJSONを書き出す。未同期の変更が自動で統合されるわけではありません。
4. ローカル試用・模擬データのUI動作確認は済んでいますが、**実Supabase接続での2端末競合・iPhone Safari実機の動作確認はまだ**。公開版への切替は別判断。

## 今日の午後の家族相談
- まずは資金計画の単独HTMLか、上記の統合版を**1端末で**利用。
- 金額が未確定の項目は空欄のままにする（0円と区別）。
- 「理想構成」「費用重視」「最小構成」を比較。
- 終了時に資金計画内の「JSON保存」も利用すると、後で再開しやすい。
